================================================================================
1. VISIÓN GENERAL
================================================================================

Huerto Hogar es una aplicación de e-commerce completa que permite a los usuarios:
- Navegar y filtrar productos orgánicos
- Registrarse y autenticarse
- Agregar productos al carrito
- Realizar compras a través de un proceso de checkout integrado
- Procesar pagos simulados con Transbank

================================================================================
2. ARQUITECTURA
================================================================================

FRONTEND (React.js - Puerto 5173)
├── Componentes React modulares
├── Context API para estado global
├── React Router para navegación
└── Bootstrap 5 para estilos

BACKEND - 3 MICROSERVICIOS:
├── Productos (Puerto 8080): Catálogo y detalles de productos
├── Ventas (Puerto 8081): Procesamiento de órdenes y pagos
└── Usuarios (Puerto 8082): Autenticación y perfiles

BASE DE DATOS:
└── PostgreSQL alojada en AWS

5. FLUJO DE UN PEDIDO
================================================================================

1. Usuario se autentica
2. Navega catálogo de productos
3. Agrega productos al carrito
4. Revisa carrito
5. Inicia proceso de checkout
6. Sistema pre-carga datos del usuario
7. Usuario confirma información
8. Se procesa pago con Transbank
9. Se muestra confirmación de orden
10. Carrito se vacía

8. COMPONENTES CLAVE DEL FRONTEND
================================================================================

AuthContext.jsx
├─ Maneja autenticación de usuarios
├─ Persiste sesión en localStorage
└─ Proporciona estado global para toda la app

CartContext.jsx
├─ Gestiona carrito de compras
├─ Calcula totales automáticamente
└─ Persiste items en localStorage

routes.jsx
├─ / → Home
├─ /productos → Listado de productos
├─ /productos/:codigo → Detalle del producto
├─ /carrito → Carrito de compras
├─ /login → Autenticación
└─ /contacto → Contacto

CheckoutForm.jsx
├─ Formulario de pago
├─ Auto-completa datos del usuario
└─ Integra con microservicio de ventas
